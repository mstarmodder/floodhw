# floodhw
example firmware for raspberry pi pico 2 (bare metal)

# features
hw features (gpio and clocks)
uart output

# how to build
install these packages: arm-none-eabi-gcc gmake python3 build-essential

clone the repo

run make

upload the firmware on your pico

# how to get uart output
get a generic usb to ttl adapter

connect TX to pin 1, RX to pin 2, GND to pin 3
